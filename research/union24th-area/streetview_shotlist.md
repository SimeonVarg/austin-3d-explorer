# Street View shot list — Union on 24th surroundings

The sandbox can't pull Google Street View (needs an API key), but the desktop
CAN: open each link in a browser, screenshot, and drop the capture into the
image-analysis system. Each building gets 8 viewpoints on a ring around it,
one per 45° — N/NE/E/SE/S/SW/W/NW — so every facade is covered from a
standard angle. The link's heading already points the camera at the building;
Street View snaps to the nearest street photo, so some viewpoints (mid-block
alleys) may land a bit off — nudge as needed. Name screenshots
`<slug>_<bearing>.png` (e.g. `the-standard-at-austin_NE.png`) so the angle is
machine-readable.

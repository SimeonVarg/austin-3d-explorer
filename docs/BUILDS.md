# Which model built which building

The owner (2026-10-14): "There should be a list for what model built what building, for futures sake when better models come out and cheaper ones, they know what to target."

This is that list. One row per BUILD of a Blender building: a building can have several (trials, redos, fix rounds), and each building has one current best. A model that sees this file should know where it is worth trying: where the best build is by a weaker or cheaper model, where the owner scored it under 8, or where the best build has a known open fault. Scores are the owner's own numbers; a blank means he gave none. Minutes are builder time; cost is plan tokens for Claude models and dollars for paid models. Triangle counts are the saved model's. Sources are site photographs and public pictures; none are named here.

**How the retarget flag is set.** Yes when the best build is by a weaker or cheaper model than Opus 5.5; or the owner scored it under 8; or it has a known open fault (camera not proven, scale or outline off by more than about 3 m or 10%, a part missing or only inferred, name unconfirmed, whole-build colour gate failed, too many triangles for the phone); or there is no finished build yet. A fault that every build has (glass a little light, far sides inferred) does not count. Colour faults from before the standard light (2026-10-12, evening) count only when the whole build missed.

Right now: 212 builds of 161 buildings; 61 buildings flagged to retarget.
